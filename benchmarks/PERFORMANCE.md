## Synthetic corpus scaling

**Latency only.** The chunk set is replicated N times (copy i's slugs suffixed `~i`) and indexed into a temporary ChromaDB directory (HNSW ef_search=400; once an index holds more chunks than that, the search is approximate) plus a fresh BM25 index; identical texts are embedded once, since their vectors are the same. `route(query, k=10, pool=20)` (hybrid RRF, no cross-encoder) is timed on the first 50 queries, passes interleaved across scales. `dense` includes the query embedding, which does not depend on the corpus size. Every answer has N identical copies, so **quality on these duplicated corpora is not meaningful** and is not reported. These numbers describe this machine only.
